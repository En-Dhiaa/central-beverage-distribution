========================================================================
نظام إدارة وتشغيل ثلاجة المياه والعصائر المركزية (Enterprise v1.3.0)
دليل التثبيت والتشغيل السريع والمباشر (Quick Start Guide)
========================================================================

1. طرق التثبيت المتاحة:
----------------------
الخيار (أ) - المعالج الرسومي الذكي (موصى به):
   - شغّل الملف التنفيذي:
     CentralBeverageDistribution-Setup.exe
   - سيفتح لك معالج التثبيت باللغة العربية.
   - اختر مسار التثبيت (أو اترك الافتراضي).
   - يمكنك تحديد هوية المؤسسة ورقم السجل والعنوان.
   - اضغط "بدء التثبيت" وسيقوم بتهيئة كل شيء وتشغيل النظام مباشرة.

الخيار (ب) - التثبيت السريع عبر السكربت:
   - انقر نقراً مزدوجاً على الملف:
     install.bat
   - سيقوم بتثبيت الملفات وإعداد اختصار سطح المكتب فوراً.

الخيار (ج) - التشغيل المحمول (Portable Run):
   - ادخل إلى مجلد payload/
   - شغّل مباشرة:
     CentralBeverageDistribution.exe
   - سيعمل النظام محلياً وفورياً دون أي تثبيت مسبق.

2. بيانات الدخول الافتراضية:
----------------------------
• اسم المستخدم: admin
• كلمة المرور: Admin@123456

3. المميزات المضمنة في هذه النسخة:
----------------------------------
✓ تطبيق أصلي لنظام Windows بأيقونة رسمية مخصصة.
✓ استضافة ذاتية داخلية كاملة لمحرك ASP.NET Core 8 و Kestrel.
✓ واجهة مستخدم React 18 و TypeScript مدمجة ومجزأة فائقة السرعة مع دعم كامل للعربية RTL و LTR.
✓ لوحة تحكم قابلة للتخصيص وإعادة ترتيب البطاقات مع حفظ الإعدادات تلقائياً.
✓ مؤثرات صوتية تفاعلية offline via Web Audio Synthesizer.
✓ قاعدة بيانات SQLite محلية لا تحتاج لأي سيرفر خارجي، مع دعم التبديل إلى PostgreSQL للعمل الشبكي.
✓ نقطة بيع سريعة (POS)، فواتير مبيعات، عروض أسعار، مرتجعات، عهد موزعين وتسويات يومية صارمة.
✓ طباعة فواتير حرارية POS وطباعة رسمية A4.
✓ إغلاق يومي وتسويات نقدية ومخزنية.
✓ دليل توثيق API عبر Swagger متاح عند التشغيل على: http://localhost:5000/swagger
