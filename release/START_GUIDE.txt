نظام إدارة وتشغيل ثلاجة المياه والعصائر المركزية | Central Beverage Distribution
دليل البدء السريع ومعلومات التثبيت (Version 1.1.0 Enterprise Production)
========================================================================

1. متطلبات التشغيل:
- نظام تشغيل: Windows 10 أو Windows 11 (64-bit).
- بيئة التشغيل: .NET 8 Desktop Runtime (مثبتة مسبقًا أو محملة آليًا).
- WebView2 Runtime (مدمج افتراضيًا في Windows 10/11 الحديثة).

2. بيانات الدخول الافتراضية (مسؤول النظام العام):
- اسم المستخدم: admin
- كلمة المرور: Admin@123456
- الدور: SuperAdmin (مدير النظام العام بكامل الصلاحيات)

3. حالة قاعدة البيانات:
- قاعدة البيانات جاهزة وفارغة تمامًا من أي بيانات تجريبية أو وهمية.
- مهيأة فقط بالبنية التأسيسية المعتمدة:
  • دليل الحسابات المالي الموحد (10 حسابات معيارية للقيود المزدوجة).
  • الوحدات القياسية (كرتون، حبة، باكت، شرنك).
  • المستودعات الرئيسية (المستودع الرئيسي للاستلام WH-MAIN، الثلاجة المركزية للتبريد WH-COLD).
  • بنود المصروفات التشغيلية (كهرباء وتبريد، ديزل ونقل، رواتب، إيجارات، صيانة).
  • التصنيفات الرئيسية للمشروبات (مياه معدنية، عصائر طبيعية، مشروبات غازية، مشروبات طاقة).
  • الصندوق النقدي الرئيسي (برصيد صفري نظيف).

4. طريقة التثبيت:
- الخيار الأول: تشغيل برنامج التثبيت الرسومي:
  CentralBeverageDistribution-Setup.exe
- الخيار الثاني: تشغيل التثبيت السريع:
  انقر نقرًا مزدوجًا على install.bat

5. مسار التثبيت الافتراضي:
%LocalAppData%\CentralBeverageDistribution\

6. الدعم الفني وتحديثات النظام:
تم بناء وتطوير النظام بواسطة Antigravity AI لصالح مؤسسة ضياء لإدارة وتوزيع المشروبات.
مستودع المشروع على GitHub:
https://github.com/En-Dhiaa/central-beverage-distribution
