نظام إدارة وتشغيل ثلاجة المياه والعصائر المركزية | Central Beverage Distribution
دليل البدء السريع ومعلومات التثبيت (Version 1.2.0 Offline Enterprise Release)
========================================================================

1. طبيعة النظام والتشغيل المحلي (100% Offline):
- النظام يعمل بصورة محلية كاملة دون الحاجة إلى أي اتصال بشبكة الإنترنت.
- لا توجد أي بيانات وهمية أو تجريبية؛ النظام مهيأ بالبنية الصفرية المعتمدة وجاهز فورًا لبدء إدخال بياناتك الفعلية.
- يتضمن مثبتًا تنفيذيًا واحدًا ومستقلاً يثبت جميع المكونات ذاتيًا بنقرة زر واحدة.

2. ملف التثبيت الموحد (Single Standalone Setup):
- الملف: CentralBeverageDistribution-Setup.exe (ملف تنفيذي فردي مدمج بالكامل).
- يقوم هذا الملف بمفرده باستخراج كافة ملفات النظام، إعداد محرك قواعد البيانات، إنشاء مجلد حفظ البيانات المحلي، وتثبيت اختصارات سطح المكتب وقائمة ابدأ.

3. مسار حفظ البيانات وقاعدة البيانات المحلية (Local Data Vault):
- يقوم النظام آلياً بإنشاء مجلد البيانات المحلي المخصص داخل مسار التثبيت:
  [InstallationFolder]\Data\
  • Data\beverage_system.db (ملف قاعدة البيانات التشغيلية المحلي).
  • Data\invoices\ (أرشيف فواتير الشراء والبيع والمطبوعات).
  • Data\reports\ (أرشيف تقارير الحركة اليومية والإقفالات).
  • Data\attachments\ (أرشيف صور المستندات وسندات القبض والشيكات).
  • Data\backups\ (أرشيف النسخ الاحتياطية الدورية لقاعدة البيانات).

4. بيانات تسجيل الدخول الافتراضية (مسؤول النظام العام):
- اسم المستخدم: admin
- كلمة المرور: Admin@123456
- الصلاحية: SuperAdmin (مدير عام بكامل الصلاحيات)
(يمكنك تغيير كلمة المرور وإضافة مستخدمين ومحاسبين من شاشة الإعدادات داخل البرنامج).

5. متطلبات التشغيل:
- نظام تشغيل: Windows 10 أو Windows 11 (64-bit).
- شاشة بدقة 1024x768 أو أعلى.
- يعمل بكفاءة على الأجهزة الفردية أو ضمن شبكة محلية داخلية (Local Area Network).

6. خطوات التثبيت والتشغيل:
1) شغل الملف التنفيذي: CentralBeverageDistribution-Setup.exe
2) انقر [التالي] واختر مسار التثبيت (الافتراضي: C:\CentralBeverageDistribution).
3) انقر [تثبيت الآن].
4) بعد ثوانٍ سينتهي التثبيت، انقر [إنهاء والبدء] لفتح النظام مباشرة.
5) سجل الدخول باستخدام admin و Admin@123456 وابدأ العمل!
